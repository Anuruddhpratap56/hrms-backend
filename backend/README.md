# HRMS Lite Backend (FastAPI)

## Stack
- FastAPI
- SQLAlchemy Async
- PostgreSQL
- Alembic
- Pydantic
- fastapi-pagination

## Setup
1. Create and activate venv:
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

2. Install dependencies:
```powershell
pip install -r requirements.txt
```

3. Configure environment (`.env`):
```env
DATABASE_URL=postgresql+psycopg2://postgres:password@localhost:5432/hrms_lite
```

4. Run migrations:
```powershell
alembic upgrade head
```

5. Start server:
```powershell
uvicorn app.main:app --reload --port 8000
```

## API Endpoints

### Health
- `GET /health`

### Employees
- `POST /api/v1/employees`
  - Request body:
  ```json
  {
    "full_name": "test",
    "email": "test@example.com",
    "department": "Engineering"
  }
  ```
  - `employee_id` is generated by backend (`emp00<sequence>`)

- `GET /api/v1/employees?page=1&size=10&search=john&date=YYYY-MM-DD`
  - Returns employees + day-wise attendance status (`is_present`) for selected date
  - If `date` is missing, backend uses current day

- `DELETE /api/v1/employees/{employee_id}`

### Attendance
- `POST /api/v1/attendance`
  - Toggle endpoint for a specific employee and date
  - If attendance exists: unmarks (deletes)
  - If not exists: marks present
  - Request body:
  ```json
  {
    "employee_id": "emp001",
    "date": "2026-02-20",
    "is_present": true
  }
  ```

- `GET /api/v1/attendance?page=1&size=10&date=YYYY-MM-DD&employee_id=emp001&search=john`
  - Returns attendance list with employee name
  - If `date` is provided, includes both present and absent employees for that day

- `GET /api/v1/attendance/{employee_id}?page=1&size=10&date=YYYY-MM-DD`
  - Returns attendance history for a single employee

## Validation & Errors
- Required field validation (`422`)
- Invalid email format (`422`)
- Duplicate email on create (`409`)
- Employee not found (`404`)
- Validation handler returns specific error message in `detail`

## Assumptions
- Single admin user (no auth)
- Attendance marking is toggle-based
- `is_present=true` means Present, missing record (in date-wise full list) is treated as Absent
